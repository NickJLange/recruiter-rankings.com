## Design
The demo must fail closed unless explicitly enabled and attached to an independently verified local disposable PostgreSQL database. Only bounded fictional targets and actors can be mutated. Requests must be same-origin and server validation must constrain all input. Shared state must be prominently disclosed; reset must affect only demo-owned records. Call the existing RR-8 submit and moderate functions, retaining its transactional and aggregate rules. Public profiles must never expose pending data. The existing preview services remain unchanged until independent audit.
